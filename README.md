# headywater

Independent brand website for Headywater: sparkling water from Italy with a visual identity informed by connoisseur and functional-glass culture.

## Development

Node 24.x; no runtime dependencies. Run `npm run check` and `npm run build`. Serve `dist/` with a static HTTP server. Source is plain HTML, CSS and JavaScript, with no database or connection to Operator credentials.

## Preview boundaries

Packaging is a CSS design study, not confirmed production packaging. Brand copy is a proposal; only Italian origin and sparkling-water product category were supplied. No mineral, source-town, ingredient, cannabinoid, certification, availability or health claims are made. No checkout, customer collection, or invented contact details are included. Sharing uses the browser's native share UI or clipboard.

The preview is noindex. Review final brand copy, packaging, legal trademark use, product details and purchase/contact destination before a public launch. Do not change GoDaddy DNS until the owner approves the site. Google Fonts is used with system fallbacks.

## Research

- https://www.headie.com/pages/glossary-term/heady-glass — cultural context for heady artistic glass.
- https://weedmaps.com/learn/products-and-how-to-consume/terp-slurper-heady-dab-guide — broader cultural terminology.

## Operator handover

Keep this repository and its separate Vercel project. Operator can later connect to these same resources; do not copy its credentials into this site. The site needs no service tokens. The build output is a static `dist/` directory, suitable for an adapter that commits and deploys reviewed revisions.
